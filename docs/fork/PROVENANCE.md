## Microsoft Skill Recorder – Codebasis

Original: https://github.com/microsoft/skill-recorder

Ausgangsversion: 0.7.0, Commit `b05d59036182e897e1a60e90651e775cf5f97e8d`.

Microsoft Skill Recorder stellt die Recorder-, Sitzungs-, Analyse- und Skill-Builder-Basis bereit. Die Weiterentwicklung ergänzt den Prozesseditor, flexible Fensteranordnung, Markenanpassung, Prozessbewertung, zusätzliche Ausgaben und Wiki-Grundlagen. Die MIT-Lizenz und der Copyright-Hinweis von Microsoft bleiben unverändert erhalten.

Dieses Repository enthält einen bereinigten Quellstand einschließlich der aktuellen Studio-Erweiterungen. Eine neue Git-Historie verhindert die Übernahme früherer projektspezifischer Daten und Metadaten; die Codeherkunft wird dadurch nicht geändert.

## OpenSteps – funktionale Referenz

Original: https://github.com/ebanez8/openstep

OpenSteps ist die Referenz für visuelle Schritt-für-Schritt-Dokumentation und Screenshot-orientierte Abläufe. Es wurde kein OpenSteps-Code in diese Anwendung kopiert. Das Originalprojekt veröffentlicht seinen Code unter MIT; seine Lizenz gilt für das Originalprojekt, nicht als zusätzliche Lizenzbehauptung für diesen Quellstand.

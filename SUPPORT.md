# Support

Report reproducible problems with this fork through its [GitHub Issues](https://github.com/friedensbringer-peacemaker/workflow-studio/issues). Include the version, operating system and sanitized reproduction steps. Never attach credentials, unredacted recordings, customer data or a complete user profile.

This is an independent development fork with no support service-level agreement. Microsoft and OpenSteps do not provide support for changes made in this repository. See [SECURITY.md](SECURITY.md) for security-related reports.
